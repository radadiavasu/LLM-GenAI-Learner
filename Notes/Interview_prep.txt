Q. Why do we convert models to ONNX and TensorRT?

Ans: PyTorch carries heavy Python runtime overhead because Python orchestrates every layer step-by-step. By converting to ONNX, we save the model as a static blueprint and run it using ONNX Runtime (written in C++). This removes the Python bottleneck, shrinks the deployment size, and lets the C++ engine optimize the entire graph at once and TensorRT goes one step further by compiling that graph directly into custom machine code for a specific NVIDIA GPU.

Q. What is bias–variance tradeoff?

Ans: This is about finding balance between simplicity and complexity of the model.

if High Bias: Means model is too fitting. Underfitting problem so it can't learn well.

if High Variance: Means model is too complex. Overfitting problem where it sticks with training data means it performs well on training data but not on un-seen (validation) data.

So we tune model complexity add regularization techniques like L1/L2, add optimization techniques like dropout or random forest, use cross-validation on data, so we get low variance & low bias.
